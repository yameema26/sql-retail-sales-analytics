# Retail Sales and Customer Analytics

## Project Overview

This project uses SQL and MySQL to analyse retail sales and customer
purchasing behaviour. It covers data cleaning, product performance,
sales trends, and customer purchase patterns to derive meaningful
business insights.

## Objectives

- Clean retail data by identifying duplicates, correcting prices,
  handling missing values, and standardising data formats.
- Analyse product sales and identify the top and bottom 10 products
  by sales.
- Examine daily sales trends and month-on-month sales growth.
- Analyse purchase frequency, repeat purchases, and customer segments.

## Tools and Technologies

- SQL
- MySQL
- MySQL Workbench

## Key Analysis Areas

### 1. Data Cleaning
Identified duplicate records, handled missing values, corrected
prices, and standardised data formats.

### 2. Product Performance
Analysed sales performance to identify the top and bottom 10 products.

### 3. Sales Trend Analysis
Examined daily sales trends and calculated month-on-month sales growth
using SQL aggregation.

### 4. Customer Analytics
Used SQL queries and date functions to examine purchase frequency,
repeat purchases, and customer segments.

## Skills Demonstrated

- SQL querying and data aggregation
- Data cleaning and standardisation
- Sales trend analysis
- Product performance analysis
- Customer purchasing behaviour analysis
- Working with relational databases
